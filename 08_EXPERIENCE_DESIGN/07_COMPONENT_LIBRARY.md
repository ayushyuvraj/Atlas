# Component Library

## Document Status

**Layer:** 8 - Experience Design
**Version:** v1.0
**Status:** Frozen
**Source:** Derived from Layer 7 requirements and Layer 8 design system.
**Purpose:** Define the MVP component inventory required for Atlas.

---

## Navigation Components

| Component | Purpose |
| --- | --- |
| App Shell | Persistent product frame |
| Side Navigation | Access Home, Decisions, Templates, Memory, Insights, Administration |
| Breadcrumb | Show current workspace location |
| Search Bar | Search decisions, evidence, and memory |

---

## Decision Components

| Component | Purpose |
| --- | --- |
| Decision Header | Title, status, owner, deadline, priority |
| Lifecycle Rail | Shows decision lifecycle stage |
| Decision Summary Panel | Shows objective, constraints, and key metadata |
| Decision Template Picker | Starts a decision from a structured template |
| Decision Record Panel | Captures committed decision and rationale |

---

## Reasoning Components

| Component | Purpose |
| --- | --- |
| Context Brief Panel | Summarizes decision context |
| Evidence Table | Lists evidence with type, owner, confidence, and source |
| Assumption Map | Shows assumptions, confidence, owner, and status |
| Scenario Comparison Table | Compares options across evaluation dimensions |
| Tradeoff Matrix | Shows benefits, costs, opportunity costs, and reversibility |
| Risk Register Panel | Shows risks by category, severity, and mitigation |
| Recommendation Panel | Shows AI-assisted recommendation and rationale |
| Reasoning Trace Drawer | Shows how the recommendation was generated |

---

## Collaboration Components

| Component | Purpose |
| --- | --- |
| Comment Thread | Capture review comments |
| Challenge Control | Let users challenge assumptions, evidence, or recommendation |
| Review Activity Feed | Show meaningful review history |
| Human Approval Badge | Distinguish approved content from generated content |

---

## AI Components

| Component | Purpose |
| --- | --- |
| AI Output Label | Identify AI-generated content |
| Confidence Indicator | Show confidence level and reason |
| Missing Evidence Alert | Warn when recommendations are weakly grounded |
| Reasoning Progress Indicator | Show AI reasoning progress |
| Regenerate or Revise Control | Re-run reasoning after new inputs |

---

## Feedback Components

| Component | Purpose |
| --- | --- |
| Empty State | Explain what is missing and what to do next |
| Inline Error | Show field-level errors |
| Warning Banner | Show evidence, risk, or governance warnings |
| Loading State | Show system activity |
| Success State | Confirm meaningful completion |

---

## Decision

Freeze this component library as the MVP component inventory for Atlas.
