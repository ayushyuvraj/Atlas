## Repository Positioning

Atlas is a public product repository for a working Enterprise AI MVP and the product operating system behind it.

It should be presented as:

> A complete product program for an Enterprise Decision Operating System, including strategy, customer intelligence, decision science, PRD, UX, architecture, business strategy, validation, MVP build, and launch package.

## README Positioning Principle

The README should help a serious reviewer understand:

- What Atlas is.
- Why the problem matters.
- What has been built.
- How the repository is organized.
- What is MVP versus future work.
- How to run the MVP locally.
- What claims are intentionally not being made.

## Suggested Pinned Repository Blurb

Atlas is a working MVP and end-to-end product program for an Enterprise Decision Operating System. It demonstrates how strategic investment decisions can be structured through evidence, assumptions, scenarios, tradeoffs, recommendations, Decision Records, and institutional learning.
